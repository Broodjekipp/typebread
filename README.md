# typebread
A terminal-based typing test, written fully in Python, inspired by [Monkeytype](https://monkeytype.com).

### Features:
- WPM and accuracy calculation
- Cool (inaccurate) [plottile](https://pypi.org/project/plotille/) graph
- Results saving (not viewing yet, but it'll come)
